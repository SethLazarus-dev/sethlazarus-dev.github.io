# Seth Lazarus — Portfolio

A responsive portfolio for an NC State computer science student and Goodnight Scholar. Built with HTML, CSS, and a small JavaScript enhancement, with no build step or external dependencies.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static web server. For example, `python -m http.server 8000`, then visit `http://localhost:8000`.

## Files

- `index.html`: profile, projects, background, skills, and contact links.
- `styles.css`: responsive light theme and reduced-motion support.
- `script.js`: optional copy-email button, available in secure browser contexts.
- `favicon.svg`: site icon.
- `assets/goodnight-scholars-logo.png`: supplied Goodnight Scholars logo used in the About section.

## GitHub Pages

The site is ready for GitHub Pages with the publishing source set to the root of `main`. A review branch does not replace the published site until it is merged into the configured publishing branch.

The public contact address is `sethlazarus.dev@gmail.com`. Phone numbers, the previous personal email, and the original résumé document are not included. Project illustrations are decorative concepts, not application screenshots. Planned Howling Cow features are identified as planned.

Update project descriptions and academic details in `index.html` as work progresses. Project cards expand to show more information; individual repository links can be added when available.
